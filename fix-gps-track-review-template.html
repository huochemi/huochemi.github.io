轨迹审阅 ·

1 · 地图核对

蓝线 = GPX 轨迹；带序号的蓝点 = 相机照按拍摄时刻插值得到的落点（序号即拍摄顺序）； 橙点 = 手机锚点照的原生 GPS（唯一的外部真值）。点下方卡片可在地图上定位。 注意：落点必然落在轨迹线上——绑对没绑对要看顺序与相对锚点的位置，不是看"在不在线上"。
轨迹 / 相机照落点（按时间编号） 手机锚点照（原生 GPS） 已排除（不写入）

2 · 落点清单（按拍摄时间，可逐张排除）

取消勾选 = 这张不写入（本轮跳过）。其余照样写入——本通道"能补就补"，不会因为一张被排除就整批不动。

3 · 时间窗之外（本通道不写）

这些照片的拍摄时刻不在轨迹覆盖范围内（轨迹只覆盖"按下记录"之后的时段）。它们交给锚点路：npm run fix-gps:anchor -- "<文件夹>" --review（已写入的照片会被自动跳过）。

4 · 将写入的轨迹计划

核对满意后：点「复制写入命令」→ 回终端粘贴、回车 → 打印摘要后按一次 y 写入。命令自带 JSON（单行压缩），剪贴板只复制这一次。
